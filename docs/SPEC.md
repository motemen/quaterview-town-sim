# クオータービュー箱庭都市シミュレータ 仕様

PC版「A列車で行こう3」をイメージした、勝手に成長しずっと動き続ける箱庭都市。
眺めることが主目的で、プレイヤーは街づくりに介入しない。

## 決定事項

| 項目 | 決定 |
| --- | --- |
| 技術 | Vite + TypeScript、Canvas 2D。外部素材なし（ドット絵はコード生成） |
| 画面 | タイル 32×16px のクオータービュー。整数倍（2〜3倍）に拡大してドット感を出す |
| マップ | 256×256 マス、固定サイズ。埋まったあとは建て替え・衰退で変化し続ける (テストは 64×64 で回す) |
| 地形 | 高さ 0〜3 の起伏（頂点ベース、隣接差 ≤1）、水面（海・川・池）、森・草地。野原はノイズで 4 種 (ふつう・灌木・草花・枯れ草) に分かれ、まばらな木立もある。建物は平地のみ。道路・線路は坂を登れる |
| 時間 | 現実 1 分 ≈ ゲーム内 1 日（x1 時）。速度 x1 / x4 / x16、一時停止 |
| 昼夜 | あり。夜は窓に明かり、街灯、列車のヘッドライト |
| 季節・天候 | 春（桜）夏（濃緑）秋（紅葉）冬（雪）、ときどき雨・雪 |
| 鉄道 | 単線が最初からマップを横断し、駅 1 つから開始。カーブは斜め区間で 135°。発展した場所に新駅が開業。列車は同じ向きに最大 4 本まとめて走り、全部抜けたら逆向き |
| 道路 | 駅から自動で少しずつ伸びる。建物数に対して道路が多いと伸びない (上限 0.6×建物数+12、0.45×建物数+8 を超えると頻度を下げる)。行き止まりからまっすぐ数マスずつ伸び、曲がる・枝分かれは直進できないときや交差点から離れたところだけ。踏切、橋あり |
| 成長ロジック | 地価ベース。駅・道路からの距離と周囲密度で地価が決まり、住宅→商業→高層へ建て替わる。遠い地区は衰退して空き地→草地に戻る |
| 動くもの | 列車、建設中のクレーン・足場、煙突の煙、ネオン等の環境演出。自動車・歩行者はなし |
| 田畑 | 地形生成時に平らな低地へ長方形の区画を置く (田・畑・花畑・果樹園)。区画の縁に農道 (草地の中の細い轍)。区画の境目だけに畦があり、区画内は畝が続く。北や西の縁に防風林が並ぶことがある。地価の低い田舎では広がり、地価が上がると建物に置き換わる |
| 神社 | 地形生成時に森の中の高台へ 1 つ。鳥居・社殿・参道・灯籠。周囲の地価に少し加点 |
| 建物の種類 | 民家 (大きさ・階数・屋根の形と向き・色がスタイルで変わる)、商店・アパート (アパート / レストラン / コンビニ / 小売店)、雑居ビル (看板・屋上広告塔、夜はネオン)、中層・高層ビル (12〜26 階、建設時の地価で高さが決まる) |
| 2×2 タワー | 地価 100 以上で高層ビルが建つとき、6 割の確率で周囲 2×2 (隣の築 30 日以上・レベル 4 以下の建物は取り壊す) を確保して 28〜42 階の超高層タワーになる。アンカーは右下のタイル、他 3 タイルは BuildingPart。取り壊されない |
| 一軒家 | 田畑や農道のそばの野原に、道路がなくてもごくまれに民家が建つ |
| 操作 | カメラのドラッグ移動・ズーム、速度変更・一時停止、月単位のジャンプ、クリックで情報表示、ミニマップ (クリックで移動) |
| HUD | 画面下に小さなステータスバー（町名・年月日・時刻・人口・テロップ）。速度は 1 つのボタンをクリックで ❚❚→▶→▶▶→▶▶▶ と循環。ジャンプ・ミニマップ・音・スクリーンショット (📷)・録画 (⏺)・リセットはアイコンボタン。スマホでは状態・テロップ・ボタンの 3 段にして文字とボタンを大きくする。マスの情報は左上のパネル |
| 永続化 | localStorage に自動保存。シードは URL (`?seed=...`) で共有可能。リセットで新シード |
| 追加演出 | ランドマーク建築（人口の節目でタワー等）、季節イベント（夏の花火、桜吹雪、年末イルミ） |
| 音 | Web Audio 生成の環境音（列車音、踏切、雨）。デフォルトオフ |
| 公開 | GitHub Pages に GitHub Actions で自動デプロイ |

## 段階 (すべて実装済み)

1. **コア**: 地形生成、線路と駅（静的）、道路成長、建物の建設・建て替え・衰退、昼夜、カメラ、HUD、保存、シード共有、デプロイ設定
2. **鉄道**: 列車の走行、新駅開業、踏切の動作
3. **季節・演出**: 季節と天候、ニューステロップ、ランドマーク (市役所・タワー・観覧車)、季節イベント (夏の花火・春の桜吹雪・12 月のイルミネーション)、環境音 (列車・踏切・雨・鳥・虫・花火、デフォルトオフ)

## 鉄道の仕組み

- 支線: 人口 2,500 人以上で、半径 10 マスに建物が 12 軒以上ある本線の駅から、10 日ごとの判定で支線を計画する (駅数の半分まで、最大 4 本)。駅の東か西の隣の線路タイルから 135° で 2 マス斜めに出て、北か南へ 18〜31 マスまっすぐ伸び、終点に駅を置く。1 日 2 マスずつ建設され、通る地形は線路の高さ 1 に均す (傾いた建物・道路は片づける)。水面は 4 マスまで鉄橋で渡る。開通すると 2 両の列車が往復する。
- 線路の接続マスク (railMask) は保存する。本線は生成時に経路から計算し、支線は建設時にビットを足す。

- 水面を渡るところは鉄橋。鉄橋の頂点も線路と同じ高さ 1 に固定するので坂にならない。水面はつねに高さ 0 の平面として描き、桁は線路の高さに橋脚で支える。道路の橋は欄干つき。
- 線路は 1 本の単線で、列車は西端または東端から現れて反対側へ抜ける。1 本ずつしか走らない。
- 人口が増えると列車の間隔が短くなる。各駅に停車する。
- 列車は保存しない (再読み込みで消えてよい)。
- 10 日ごとに、既存の駅から 14 マス以上離れた直線区間で、駅前候補の側 6 マス以内に建物が 18 軒以上あれば新駅が開業する。
- 踏切は列車が近づくと遮断機が降り、警報灯が点滅する。
- 描画: 静的レイヤーは 32×32 マスのチャンク単位のキャンバス (最大 16 枚を LRU で保持)。見えているチャンクだけ描き、1 時間ごとにタイルの変化を検出して、変化したタイルの周り (タイルとその上に伸びるスプライトの範囲を消して、そこに描き込みうるタイルを奥から描き直す) だけを更新する。1 チャンクで変化が多いとき (24 タイル超) や季節が変わったときはチャンク全体を描き直す。チャンクの下にあるタイルは、スプライトが届くものだけ描く。1 フレームの描き直しはタイル数で予算管理する (チャンク 3 枚ぶん)。その上に列車と遮断機だけを毎フレーム描く。列車の手前のタイルを列車の矩形にクリップして描き直し、建物の陰に隠れるようにしている。

## スプライトのメモリ

- 生成したドット絵は 1024×1024 のアトラス (最大 16 ページ) に詰めて保持する。小さなキャンバスを数千個作ると GPU メモリ不足でキャンバスの中身が失われ、静的レイヤーが消えてしまったため。
- 棚は高さの区分 (8px 刻み) ごとに持ち、高さの違うスプライトが混ざって隙間ができないようにする。建物の本体スプライトは明かりパターン (lights) に依らないので、同じ建物の別パターンと共有する。
- アトラスが残り少なくなったら、フレームの頭で最近 (90 フレーム以内) 使ったスプライトだけを新しいページに詰め直し (位置はその場で書き換えるので描き直しは不要)、それ以外はキャッシュから捨てる。それでも入りきらないときだけ全部捨てて作り直す。以前は全部捨てていたため、建物の種類が増えた街では数秒ごとに全スプライトの再生成と全チャンクの再描画が起きて重くなっていた。
- 窓明かりのパターンは 16 種類に限定して、スプライトの種類が増えすぎないようにしている。
- 保険として、静的レイヤーは 60 秒ごとと contextlost/contextrestored 時に描き直す。

## 構成

```
src/
  main.ts          起動、ループ
  sim/             描画に依存しない純粋なシミュレーション（vitest でテスト）
    rng.ts         シード付き乱数
    world.ts       グリッド・タイル定義
    terrain.ts     地形生成
    time.ts        ゲーム内時刻
    growth.ts      地価・道路・建物の成長
    rail.ts        線路の経路、新駅の開業
    trains.ts      列車の運行 (描画とは独立)
    save.ts        シリアライズ
  render/          Canvas 描画
    iso.ts         等角投影
    sprites.ts     ドット絵の生成
    renderer.ts    タイル描画 (TilePainter)、静的レイヤー、動的レイヤー (列車・踏切)
  ui/              カメラ・入力・HUD
```

## シミュレーションの高速化

- 建物以外のタイルの判定は 1 日 1 回。タイルごとに (x·7 + y·13) mod 24 の時刻に行う (位相ごとの index リストを事前に作る)
- 変化しうるタイル (地価 12 以上、空き地、田畑の隣、市街地に接する森) のマスクを 1 日 1 回作り、それ以外は見ない
- 建物のリストは 1 日 1 回作り直し、建設開始時に追加する。道路・建物の数は 1 日 1 回集計
- 地価計算は駅の影響を半径内だけ、密度と快適さは二次元累積和、流行ノイズは 4 マス格子の補間。作業バッファは使い回す
- ジャンプは advanceDay (advance と同じ 1 時間ステップを 24 回) で、256×256 で 1 日 20ms 程度
- 道路の延伸は通れない斜面でも、手前の辺の高さに合わせて奥の辺を揃える造成 (切土・盛土) で通せる。平地より重みは低い

## 開発メモ

- デバッグ用 URL パラメータの追加分: `&month=M` で月を変える、`&weather=1|2` で雨・雪、`&at=x,y` / `&at=lm6` (レベル 6 のランドマーク) / `&at=k9` (種類 9 = 公園、11 = 農道、12 = 神社のタイル) でカメラ位置、`&fw=1` で読み込み直後に花火。
- `pnpm dev` で開発サーバー、`pnpm test` でシミュレーションのテスト、`pnpm build` で型チェックとビルド。
- デバッグ用 URL パラメータ: `?seed=7&days=200&hour=22` で、シード 7 の街を 200 日進めた 22 時の状態から始める (保存データがないときのみ)。`&train=3` で最初の駅の 3 タイル西に停車中の列車を置く。
- 操作: ドラッグで移動、ホイールまたは +/- キーでズーム (1, 1.5, 2, 2.5, 3, 4 倍)、矢印キーか WASD で移動、スペースで一時停止、1/2/3 キーで速度切替、J / Shift+J / L で 1 日・10 日・1 か月ジャンプ (HUD のボタンでも可。1 フレームに数日ずつ処理する)、? でキー一覧、クリックでマスの情報、P でスクリーンショット (PNG)、R で録画の開始・停止 (MediaRecorder、webm か mp4、最長 2 分)。保存はキャンバスの中身だけ (HUD は含まない)。タッチ端末では共有シートで渡し、それ以外はダウンロードする。
- 初期ズームは幅 700px 超で 4 倍、それ以下で 3 倍。
